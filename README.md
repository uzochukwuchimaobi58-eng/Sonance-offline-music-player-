# Sonance Music Player (Android)

A high-fidelity native Android music player built with **Kotlin** and **Jetpack Compose**, featuring lossless audio playback, hardware-accelerated 10-band equalizer, dynamic audio effects, and versatile studio tools.

## Features

- **High-Fidelity Audio Engine**: Powered by Android Media framework with low-latency playback, gapless looping, variable speed (0.5x - 2.0x), and real-time audio effects.
- **Hardware 10-Band Equalizer & FX**: Custom 10-band frequency response (-12dB to +12dB), Bass Boost, 3D Spatial Reverb, and presets (Flat, Bass Boost, Vocal Booster, Rock, Electronic, Jazz, Acoustic, Hi-Fi Master).
- **Studio Tools**:
  - **Music Trim**: Ringtone & audio cutter with sub-second accuracy and preview.
  - **Karaoke Studio**: Real-time vocal attenuation and pitch key transposition (-6 to +6 semitones).
  - **Beat Instrumental (AI Stems)**: 4-channel isolation (Vocals, Beat/Drums, Sub Bass, Melodic Instruments).
  - **Live Audio Visualizer**: Animated soundwave frequency visualizer synced with playback.
- **Library Organization**: 6 category dashboards (Library, Folder View, Favorites, Recent Play, Recent Add, Most Played), custom playlists, and live search.
- **Specialized Playback Modes**:
  - **Drive Mode**: High-contrast, giant-button hands-free UI optimized for vehicle use.
  - **Lyrics Mode**: Synchronized LRC scrolling lyrics with line jump-to-time navigation.
- **Sleep Timer**: Flexible auto-pause timers (15m, 30m, 45m, 60m, 90m).
- **Themes & Material 3**: 9 themes including Dark AMOLED, Slate Neon, Cyberpunk, Midnight Sapphire, Sunset Amber, Emerald Forest, Crimson Ruby, Golden Luxury, and Clean Studio Light.
